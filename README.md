## 国内网络：164ms 的直连，晚高峰看运气

DC03 到国内的平均延迟约 164 到 165ms，两份测评互相印证；另一份 2026 年 2 月用一百多个节点做的测试给出的平均值是 192ms。差距可能来自节点分布和测试时段，你本地的实际数字介于两者之间都算正常。作为参照，美西普通线路一般在 180ms 上下。

三网都是双向直连，没有 CN2 GIA，也没有 CMI 优化，延迟低主要是因为洛杉矶离得近。

路由方面，2026 年 9 月更新的那份测评写的是：电信去程走 163 骨干网到圣何塞转 twelve99 进洛杉矶，回程走 Cogent 在圣何塞对接 163；联通去程 AS4837 直连圣何塞转 zayo，回程大部分直连；移动去程 CMI 到圣何塞转 zayo，回程走 CogentCo 对接移动 CMI，南方移动回程会绕道伦敦。另一份 2026 年 2 月的测评给出的路径完全不同，电信和联通去程都是直连洛杉矶接 telia，联通北京方向回程要绕达拉斯、亚特兰大、雷斯顿再经欧洲回国。同一个机房不同 IP 段走不同上游，这种情况在低价 VPS 上很常见，两份数据并不矛盾，只是抽到的段不一样。

带宽实测：三网上传下载约 500 到 600Mbps，国际互联本地同区约 800Mbps，亚洲和欧洲节点单线程 120 到 200Mbps。

晚高峰是这篇文章里最不该给你一个确定答案的部分，因为几份测评的结论互相打架：

- 一份 11 月 7 日深夜 23 点的实测显示，三网都有抖动和丢包，联通方向最严重，广东联通节点的速度掉到约 156Kbps。
- 另一份测评的结论是电信部分节点晚高峰轻微丢包，联通和移动基本零丢包。
- 还有测评认为移动的表现相对好于电信和联通，电信联通晚高峰情况不佳。

三份说法放在一起，能确定的只有一件事：晚高峰的抖动和丢包因 IP 段、省份、时段而异，联通和移动用户的体验方差最大。下单前用测试 IP 或官方 Looking Glass 在晚高峰实测一次，比看任何测评都准。要的是晚高峰稳定跑满带宽，那就得换 CN2 GIA 或 CMI 优化线路的商家，价格是另一个量级。

## IP 与解锁：TikTok、ChatGPT 能过，Netflix 只到自制剧

IP 归属 AS36352，是美国原生机房 IP，不是住宅 IP。风险库的打分是 IP2Location 3（低）、Scamalytics 20（中）、AbuseIPDB 0，没有代理、VPN、Tor 或滥用标记。

流媒体和 AI 服务的实测结果：

| 服务 | 情况 |
| --- | --- |
| TikTok 美区 | 可解锁 |
| ChatGPT | 可访问，原生解锁 |
| Claude | 可访问 |
| Netflix | 仅美区自制剧，全区不保证 |

同机房不同 IP 段的结果可以完全相反。有人的那台 Google 访问被同段邻居搞坏、Gemini 直接不可用，另一台机器上 TikTok、ChatGPT、Claude 全通。RackNerd 给的补救是下单 72 小时内在后台免费换一次 IP，超过 72 小时付费换，一次几美元。所以机器开通后第一件事是测解锁，不满意趁免费窗口换掉。
